# 📋 Gerenciador de Tarefas (To-Do List) com React

Este projeto é uma aplicação de gerenciamento de tarefas (To-Do List) desenvolvida com **React**, focada em demonstrar o uso de **Hooks**, **Context API** para gerenciamento de estado global, e **React Router** para navegação.

## 🚀 Tecnologias Utilizadas

* **React** (com Hooks: `useState`, `useEffect`, `useContext`)
* **React Router DOM** (para roteamento)
* **Context API** (para estado global das tarefas)
* **LocalStorage** (para persistência de dados)

## ✨ Funcionalidades

A aplicação permite realizar as operações básicas de um CRUD (Create, Read, Update, Delete) sobre as tarefas:

1.  **Visualizar** todas as tarefas na página inicial (`/`).
2.  **Adicionar** novas tarefas.
3.  **Editar** tarefas existentes.
4.  **Excluir** tarefas individualmente.
5.  **Persistência de Dados**: As tarefas são salvas no `localStorage` do navegador, mantendo o estado entre as sessões.
